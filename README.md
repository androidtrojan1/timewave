# TimeWave

Прототип движка времени для RTS в духе Achron и клиент на Unity к нему.

Движок работает отдельным процессом и хранит общий таймлайн. Клиент подключается по TCP и показывает мир в той точке времени, где находится игрок. Приказы можно отдавать в прошлом, настоящем и будущем. Их последствия доходят до настоящего с проходом **волн времени**.

```
┌──────────── TimeWave.Server (движок) ─────────────┐
│ Timeline: опорные кадры, журнал приказов, статистика │
│ TimeEngine: волны, планировщик, окно, хроноэнергия   │
│ Simulation: детерминированный тик (только целые)     │
└──────────▲───────────────────────────┬───────────────┘
   приказы, │ TCP 127.0.0.1:7615         │ кадры мира, таймлайн,
   прыжки,  │ [len][type][payload]       │ волны, хроноэнергия
   скорость │                            ▼
┌───────────┴── unity/TimeWaveClient ──────────────────┐
│ рендер, интерполяция, выделение, панель таймлайна     │
└───────────────────────────────────────────────────────┘
```

## Структура

| Путь | Что это |
|---|---|
| `src/TimeWave.Shared` | Протокол, игровые типы, TCP-клиент (`netstandard2.1`, подключается в Unity) |
| `src/TimeWave.Core` | Движок: симуляция, таймлайн, волны, сессия игроков, `EmbeddedLink` (`netstandard2.1`) |
| `src/TimeWave.Server` | Консольный TCP-сервер движка |
| `src/TimeWave.ConsoleClient` | Текстовый клиент и сетевой smoke-тест |
| `tests/TimeWave.Tests` | Тесты механики времени и протокола (xUnit) |
| `unity/TimeWaveClient` | Проект Unity 6.3 LTS с клиентом |

## Запуск

Нужен .NET SDK 10.

```bash
dotnet build -c Release
```

Сборка Release заодно копирует `TimeWave.Core.dll` и `TimeWave.Shared.dll` в `unity/TimeWaveClient/Assets/Plugins/TimeWave`.

```bash
dotnet test
```

```bash
dotnet src/TimeWave.Server/bin/Release/net10.0/TimeWave.Server.dll
```

Часы сервера стартуют, когда подключается первый игрок. Опции: `--port N`, `--public` (слушать все интерфейсы, для игры по сети) и `--start` (запустить часы сразу).

Консольный клиент: интерактивный режим и автоматическая проверка.

```bash
dotnet src/TimeWave.ConsoleClient/bin/Release/net10.0/TimeWave.ConsoleClient.dll
```

```bash
dotnet src/TimeWave.ConsoleClient/bin/Release/net10.0/TimeWave.ConsoleClient.dll --smoke
```

### Unity

1. Откройте Unity Hub, войдите в свой аккаунт Unity (лицензия Personal бесплатна) и добавьте проект: **Add → Add project from disk → `unity/TimeWaveClient`**.
2. Откройте проект в Unity 6000.3.26f1 и нажмите **Play** в любой сцене: объект `TimeWave` создаётся сам.
3. Режим по умолчанию — `ConnectOrLaunch`. Клиент подключается к `127.0.0.1:7615`. Если сервер не запущен, клиент сам стартует собранный `TimeWave.Server.exe`, а если не получилось и это, запускает движок прямо в Unity (`Embedded`). Режим можно сменить в инспекторе компонента `TimeWaveGame`.

Управление: ЛКМ (рамка) — выделить; ПКМ — идти или атаковать; `A` + щелчок — атака с движением; `S` — стоп; щелчок или протяжка по таймлайну — прыжок во времени; `1`–`4` — пауза / 0.5x / 1x / 2x; `Space` — вернуться в настоящее; стрелки и средняя кнопка — камера; колесо — зум.

Меню **TimeWave → Build Windows Player** собирает плеер в `Build/Windows`. Его можно собрать и без редактора:

```bash
"C:\Program Files\Unity\Hub\Editor\6000.3.26f1\Editor\Unity.exe" -batchmode -quit -projectPath unity/TimeWaveClient -executeMethod TimeWave.Client.Editor.TimeWaveBuild.BuildWindows
```

Аргументы плеера: `-timewaveHost H`, `-timewavePort N`, `-timewavePlayer N`, `-timewaveName S`, `-timewaveEmbedded`. С аргументом `-timewaveAutotest <папка>` плеер сам проходит сценарий: будущее → прошлое → приказ в прошлом → настоящее → ждёт, пока волна донесёт приказ. На каждом шаге делается скриншот, в лог пишутся строки `AUTOTEST ...`, в конце плеер выходит с кодом 0 или 1.

Можно открыть две копии клиента (например, сборку и редактор, указав разные `requestedPlayer`) и играть друг против друга. Пустое место занимает простой ИИ.

## Как устроено время

Подробно — в комментариях к `src/TimeWave.Core/TimeEngine.cs`. Кратко:

- **Таймлайн** (`Timeline.cs`) хранит приказы с привязкой к тику (неизменяемые входные данные), полные снимки мира раз в `KeyframeInterval` тиков и статистику по тикам. Снимки и статистика — производные данные: их перезаписывает последняя волна, прошедшая через этот тик.
- **Волна** (`TimeWave`) — курсор симуляции со своей скоростью. Волна настоящего идёт со скоростью 1. Фоновые волны идут быстрее (`BackgroundWaveRate`) и ходят по кругу от начала окна до конца. Игрок, который путешествует, получает свою волну.
- **Планировщик** всегда продвигает самую раннюю волну. Если волна догнала другую, та перенимает её состояние (обгон): догнавшая волна видела больше приказов.
- **Приказ в прошлом** вставляется в журнал. Настоящее меняется не сразу, а когда фоновая волна пройдёт от этого тика до настоящего. Тест `Order_in_the_past_reaches_the_present_only_through_timewaves` проверяет, что после прохода волн настоящее в точности совпадает с пересчётом с нуля.
- **Задержка распространения** — не больше `WindowTicks / (BackgroundWaves × rate)` реального времени плюс догон. По умолчанию это 4 волны со скоростью 4x на окне 300 с, то есть в пределах ~20 с. В автотесте приказ дошёл за 8–11 с.
- **Окно** движется вместе с настоящим. Всё, что выпало за его левый край, фиксируется навсегда (`Timeline.Commit`).
- **Хроноэнергия** копится в настоящем и тратится в прошлом, в будущем и на паузе. Приказы вне настоящего стоят `PastCommandCost`. Если энергия кончилась, игрока возвращает в настоящее.

Все параметры собраны в `ScenarioConfig.cs`.

## Протокол

Кадр: `[int32 длина][byte тип][данные]`, little-endian, строки как в `BinaryWriter`. Сообщения описаны в `src/TimeWave.Shared/Protocol.cs`:

- клиент → движок: `Hello`, `IssueCommand`, `JumpTo`, `SetRate`, `JumpToPresent`;
- движок → клиент: `Welcome`, `WorldFrame` (30 Гц), `TimelineStats` (2 Гц), `Notice`.

## Ограничения прототипа

- Нет тумана войны, поиска пути (юниты идут по прямой и расталкивают друг друга) и хронопорта юнитов.
- Каждая волна симулирует мир целиком. У игроков в одной точке времени нет общих волн (copy-on-write, как в Achron).
- Сервер шлёт полный кадр каждому клиенту без дельта-сжатия.
